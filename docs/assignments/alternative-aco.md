# Alternative final option Ant Colony Optimization

The course offered Ant Colony Optimization as an alternative to the selected PSO final project. This option applies ant-based search to the Traveling Salesman Problem, including the `ch130` TSPLIB instance. The objective is to find a minimum-length Hamiltonian tour through all cities and return to the starting city.

The implemented final project in this repository is PSO on Rastrigin. No ACO implementation or ACO experimental result is claimed here. The brief is retained to document the set of final-project options.

TSPLIB is the standard source library for `ch130` and related TSP instances: [TSPLIB95](https://comopt.ifi.uni-heidelberg.de/software/TSPLIB95/).
