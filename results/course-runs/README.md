# Recorded course runs

This directory contains console output and figures produced during the laboratory experiments.

- `practice-1/console-output.txt`: neighborhood and trajectory search runs on the QAP instances.
- `practice-2a/console-output.txt`: GRASP, ILS, and VNS runs. The largest VNS experiment is computationally intensive.
- `practice-2b/`: parameter-study text files and CHC convergence plots for the three QAP instances.
- `final-pso/`: two-dimensional and three-dimensional particle-trajectory figures.

The reproducible 100-update PSO benchmark is published separately under `results/reference/`. Ad hoc experiment artifacts can be written to `results/generated/`, which is intentionally excluded from version control. This keeps the course measurements separate from later executions.
